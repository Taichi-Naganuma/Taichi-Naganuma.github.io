ミトとソラ 投稿

YouTube チャンネル「ミトとソラの研究所」の運営者が、自分のチャンネルの運営に使う個人用のツールです。

できること

  • 運営者が作った動画を、運営者自身のチャンネルにアップロードする（最初は非公開）
  • 運営者が承認した動画の公開を予約する、または公開する
  • 運営者自身のチャンネルの数字（再生数、視聴時間、表示回数とクリック率など）を読み、次の投稿の参考にする

このツールは YouTube API Services を使っています。使えるのは運営者本人のアカウントだけで、ほかの人のアカウントやデータは扱いません。

About (English)

A personal tool used only by the owner of the YouTube channel "ミトとソラの研究所" to upload the owner's own videos to the owner's channel (as private first), schedule or publish the videos the owner has approved, and read the channel's own analytics. It uses YouTube API Services and is not offered to anyone else.
